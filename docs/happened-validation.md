# 发生过 V1 验收记录

## 实现范围

- `/happened`：首页、单日/记录详情、月历、回忆、标签、快速记录；时间轴、统计、搜索和事件来源设置为二级入口。
- 固定底栏为：首页 / 日历 / + / 回忆 / 标签。没有独立 Profile。
- 文字、多图、地点、心情、音乐链接、关联内容、文件及清单；手动记录可编辑/删除，系统事件可隐藏/恢复。
- 桌面追加 `happened`，复用原 AppIcon、分页及桌面美化；没有修改分页、Widget、Dock 或美化存储结构。
- 只读适配规划完成、知识卡创建、日记创建。按月缓存/增量读取、稳定来源 ID 去重；不删除或写回来源 App。

## 数据与性能

- IndexedDB `kdeji-happened-v1`：entries（账号/日期/时间复合索引、标签索引）、meta（每日一句、标签、来源开关、同步游标）、files。
- 所有记录和设置使用当前账号 ID 隔离；文件也按账号隔离。当前为设备本地持久化，不提供跨设备云同步；清除网站数据会删除本地手帐。
- 图片复用现有压缩、上传、签名 URL、媒体缓存；新照片最长边 1280、目标不超过 1 MB，懒加载/异步解码。
- 桌面不读取手帐数据。手帐按日期/月读取，初始最多 80 条；月统计只扫描当前月。知识卡使用原库只读快照缓存，日记按月 50 条分页，远程增量同步至少间隔 5 分钟。
- 规划没有独立的完成时间字段，完成事件使用已有 `updatedAt`；首次收集前已编辑过的历史规划只能采用其现有时间信息。
