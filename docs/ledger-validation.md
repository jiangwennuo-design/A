# 账本实现与验收

## 实现范围

- 新增 `/ledger`，默认打开总览；首屏为可交互的大环形图。
- 总览：月份切换、收支切换、分类高亮与账单联动、标签统计筛选、最近账单、月预算及每日趋势。
- 明细：按日期分组，月份、收支、分类、标签、账户及文字搜索，编辑和确认删除；分批显示列表。
- 快速记账：自定义金额键盘、一级/二级 Emoji 分类、账户、备注、日期、时间和多标签。
- 资产：现金/银行卡/电子钱包、初始余额、账户编辑/归档、流水和内部转账。有流水的账户不可直接删除，以保留账目关系。
- 分类：收支独立、一级/二级、新增、编辑、排序、折叠、归档；新账单只选择启用的末级分类，历史记录保留。
- 标签：独立分组、新增、编辑、颜色和删除；删除标签/分组不删除账单。
- 桌面仅增加 AppIcon 和美化列表项；原分页、Widget、Dock、壁纸及美化存储结构未修改。

## 数据保存

复用项目现有新 App 的账号隔离 IndexedDB 模式：数据库 `kdeji-ledger-v1`，对象仓库 `books`，主键为当前登录用户 ID；游客使用 `guest`。

账单、账户、分类、标签、分组、预算在同一次事务中校验并保存。保存成功后才通知界面；并发写入先读取最新状态，避免覆盖。跨标签页使用 BroadcastChannel 通知重新读取，读取结果有版本与请求顺序保护。初始化不写入空数据，读取损坏数据时显示错误，不覆盖原记录。

金额以整数分保存；小数字符串以 BigInt 转换，禁止浮点乘 100。余额由初始余额及账目派生，转账同时扣除转出账户、增加转入账户，不进入收入、支出及预算统计。分类显示百分比使用最大余数分配，合计 100.00%。预留 currency 字段，当前支持 CNY。

保存范围为本设备、当前网站来源、按账号隔离；不是云端跨设备同步。刷新、重新进入及同设备登录同账号可以读取；清理网站数据/浏览器驱逐存储会影响本地数据。
